Согласованные схемы

Загружать документы могут все посетители без входа. За один раз — до 20 файлов, размер каждого — до 25 МБ. Удаление доступно только администратору.

Управление сайтом

Документы доступны всем посетителям. Вход нужен только администратору для добавления и удаления файлов.

Регистрация не нужна для просмотра и скачивания документов. Новая учётная запись не получает права администратора.

Добавить файлы
